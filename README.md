# Blurb

Mobile-first social app for books and book reviews. Blurb uses a TikTok-style vertical feed, an ivory + burnt-orange visual system, and Supabase for auth, data and media.

## Current MVP

- For You / Following vertical feed
- Email sign-up and sign-in
- Book discovery and search
- Text, photo and video book reviews
- Half-star ratings
- Spoiler gate with book cover/title/author visible before reveal
- Likes, comments and follows
- TBR / Reading / Read / DNF / Favourites
- Reader profiles
- Installable PWA

This repository is intended to deploy directly to Netlify as a static site. The publish directory is the repository root.
